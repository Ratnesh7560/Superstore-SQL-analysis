# Superstore-SQL-analysis
Superstore Data Analysis using SQL
Project Overview

This project focuses on analyzing a retail Superstore dataset using SQL to generate meaningful business insights related to sales performance, profitability, customer behavior, and regional trends. The objective of this project is to demonstrate practical SQL skills by exploring a real-world business dataset.

The dataset contains information about customer orders, product categories, sales, profit, shipping modes, and regional markets. By writing and executing SQL queries, this project uncovers patterns and trends that help understand business performance and identify opportunities for improvement.

This project is designed to showcase SQL skills commonly used in data analysis roles such as data exploration, aggregation, segmentation, and business insight generation.

Dataset

The dataset used in this project contains transactional sales data from a retail Superstore. Each record represents an order placed by a customer and includes various attributes related to the product, customer, and sales performance.

Dataset File
superstore_dataset.csv
Key Columns in the Dataset
Order ID – Unique identifier for each order
Order Date – Date when the order was placed
Customer Name – Name of the customer
Segment – Customer segment (Consumer, Corporate, Home Office)
Region – Sales region
Category – Product category
Sub-Category – Product sub-category
Sales – Revenue generated from the order
Profit – Profit earned from the order
Quantity – Number of items sold
Ship Mode – Shipping method used
